# Maya Reynolds Therapy Website

A responsive therapy website redesign created for Dr. Maya Reynolds, PsyD, a licensed clinical psychologist based in Santa Monica, California.

The website provides a calm, welcoming experience with clear information about therapy services, therapeutic approach, office environment, and consultation.

## 🌐 Live Website

https://maya-reynolds-therapy-ruby.vercel.app

## ✨ Features

- Responsive homepage design
- Dr. Maya Reynolds profile and introduction
- Therapy services section
- Client-focused therapy information
- Therapeutic approach section
- Trauma-informed care information
- In-person and California telehealth options
- Custom "Our Office" section
- FAQ section
- Consultation request page
- Mobile-friendly layout
- Clear navigation and call-to-action sections

## 🎨 Design

The website uses a calm and professional visual style designed to create a sense of comfort and trust.

### Color Theme

- Sage green
- Warm cream
- Soft sand
- Terracotta accents
- Neutral charcoal typography

The typography combines an elegant serif style for headings with a clean sans-serif style for supporting text.

## 🚀 Getting Started

Clone the repository:

bash
git clone https://github.com/pallapudharani19-spec/maya-reynolds-therapy.git


Navigate into the project:

bash
cd maya-reynolds-therapy


Install dependencies:

bash
npm install


Start the development server:

bash
npm run dev


Open the website in your browser:

text
http://localhost:3000


## 🚀 Deployment

The website is deployed using Vercel and connected to the GitHub repository.

This project was created as part of a Front-End Developer Internship selection assignment.

The redesign focuses on transforming the original website into a personalized experience based on Dr. Maya Reynolds' profile, while maintaining a clear, accessible, and responsive user experience.
